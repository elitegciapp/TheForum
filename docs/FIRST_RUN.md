# First Run (VS Code)

## Prereqs
- Node.js LTS installed
- VS Code installed

## Steps
1. Install dependencies:
   - `npm install`
2. Start Expo dev server:
   - `npm run start`
3. Typecheck (use this at the end of every phase):
   - `npm run typecheck`

## If something breaks
- Undo the last change
- Restore a green `npm run typecheck`
- Re-apply the change in smaller steps
